# Angry Chicken Chase 🐔

A colorful endless 2D HTML5 runner made with Canvas and vanilla JavaScript. No build tools or external libraries required.

## Play locally
Open `index.html` in a modern browser. GitHub Pages will also host it directly.

## GitHub Pages publishing (simple Bangla)
1. ZIP file download করে Extract করো।
2. GitHub-এ **New repository** তৈরি করো এবং Public রাখো।
3. Extract করা ফোল্ডারের ভেতরের সব ফাইল/ফোল্ডার repository-র root-এ upload করো। `index.html` যেন root-এ থাকে।
4. **Settings → Pages** খোলো।
5. **Build and deployment**-এ Source: **Deploy from a branch** নির্বাচন করো।
6. Branch `main` এবং folder `/(root)` নির্বাচন করে **Save** করো।
7. এক-দুই মিনিট অপেক্ষা করে Pages section-এ দেওয়া website link খুলে খেলো।

## Controls
- Desktop: Space / Up arrow / W = jump; Down arrow / S = slide.
- Mobile: JUMP button, SLIDE button, DASH button.
- Sound toggle and restart included.
- Endless scoring, best score saved locally, corn collectibles, randomized obstacles, increasing speed.
